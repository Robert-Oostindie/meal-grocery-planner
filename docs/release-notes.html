Release Notes

See what's new, improved, and fixed in Meal & Grocery Planner

Version 1.2.0

February 16, 2026

✨ New Features

  • Email Authentication - Sign up and sign in with email/password in addition to Google Sign-In
  • Password Reset - Forgot password? Reset via email link
  • Email Verification - Email users receive verification emails to confirm their account
  • Meal Multipliers - Select 1x, 2x, 3x, 4x, or 5x portions when planning meals
  • Ingredient Comments - Add notes to ingredients in your meal plan (e.g., "get organic")

🚀 Improvements

  • Optimized ingredient categorization system (10-100x faster)
  • Improved grocery list aisle accuracy to 95%+
  • Enhanced keyword-based routing for common ingredients
  • Better handling of ingredient variations (fresh vs frozen, canned vs jarred)
  • Smarter text extraction that preserves critical keywords
  • Added memoization caching for faster repeat lookups

🐛 Bug Fixes

  • Fixed issue where verification emails went to spam folders
  • Resolved duplicate ingredient entries in grocery lists
  • Fixed autocomplete menu positioning in recipe editor
  • Corrected substitute group suggestions not appearing

Version 1.1.0

February 4, 2026

✨ New Features

  • Delivery Integration - Quick links to Instacart and DoorDash for each store
  • Export/Import Data - Backup your recipes and settings as JSON files
  • Expand/Collapse All - Quick buttons to expand or collapse all categories and ingredients
  • Select/Unselect All Meals - Quickly select or deselect all meals in planner

🚀 Improvements

  • Improved mobile keyboard behavior (prevents auto-zoom on inputs)
  • Enhanced substitute group suggestions with autocomplete
  • Better visual hierarchy in grocery lists
  • Optimized Firebase sync performance

🐛 Bug Fixes

  • Fixed dropdown clipping in "Other Items" section
  • Resolved issue with store selection not persisting
  • Fixed ingredient quantities not multiplying correctly

Version 1.0.0

January 31, 2026

✨ Initial Release

  • Recipe Management - Create and edit recipes with ingredients and categories
  • Meal Planning - Select meals for the week and check/uncheck ingredients
  • Smart Grocery Lists - Automatically organized by store and aisle
  • Ingredient Substitutes - Create substitute groups for flexible meal planning
  • Multi-Store Support - Shop at Aldi, Walmart, Amazon, and custom stores
  • USDA Database Integration - Powered by FoodData Central with thousands of ingredients
  • Google Sign-In - Secure authentication with cross-device sync
  • Cloud Sync - Your data syncs automatically via Firebase
  • Custom Categories - Create your own meal categories
  • Custom Stores - Add stores beyond the default options
  • Responsive Design - Works great on phone, tablet, and desktop
